# Task Management System

## Description

This project is a simple Python task management system.

Users can:

- Add tasks
- Mark tasks as complete
- View pending tasks
- View their progress

## Task Structure

Each task is stored as a dictionary containing:

- `title`
- `description`
- `due_date`
- `completed`

Tasks are stored in a list.

## Modules

### validation.py

Contains functions that validate:

- Task titles
- Task descriptions
- Due dates

### task_utils.py

Contains functions for:

- Adding tasks
- Marking tasks as complete
- Viewing pending tasks
- Calculating progress

### main.py

Contains the menu that allows the user to interact with the task management system.

## Testing

The Python files were checked using `py_compile`.

The program was also tested by adding, completing, viewing, and tracking tasks.
